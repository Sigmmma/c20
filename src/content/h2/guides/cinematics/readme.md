A cutscene is nothing more than playing animations while a camera points at bipeds. However, it requires some steps to set up, and there's quite some freedom in creating a scene, action or emotion.

# Basics
All the required basics for a simple cutscene are described in this guide.

[Setting up cinematic scenes](~01_setup)


# Custom animations
In order to play something other than generic motion on a biped, it's required to create a custom keyframe animation and import it into an in-game animation.

Afterwards, a more advanced animation can be created by making use of anchors and constraints in Blender.

[Using custom cinematic animations](~02_animations)

[Creating custom cinematic animations](~02b_animations_advanced)
